# Reference: the finished initiative

Workshop sample values, not real emission factors.

`handover/initiative-fac-factor-library/` is the Factor library initiative as the developer workshop receives it: the initiative file, the capability PRD, the UX folder, the epic and its tickets 1.1 and 1.2.

Use it only as a guide:

- Compare your own result with it when your step is done.
- If you are stuck, copy the files you need from here into the `product` folder and carry on.
- Your own run will differ in wording, in the number of requirements and in the way the work is split. That is normal. Compare the shape and the decisions.

Rules:

- Never open this folder as your VS Code workspace.
- Do not ask the assistant to read it while it plans. It would copy the answers instead of asking you. The `product` folder's `AGENTS.md` already tells it to leave this folder alone.
- The UX here comes from HTML mock-ups. In the session your UX comes from the design screenshot in `product/inputs/design/`, so your `ux-fac-factor-library` folder will have an `imports/` folder instead of `mockups/`.
